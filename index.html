🐅 飞虎出征

深圳出发 · 5天4晚 · 广西之旅

🗺️ 详细行程

第一天

🚌 深圳 → 桂林（高铁直达）

07:30 深圳北站集合出发 → 12:30 抵达桂林 → 下午游览

  • 07:30 深圳北站集合，乘坐 G高铁前往桂林
  • 12:30 抵达桂林北站，入住酒店，稍作休息
  • 14:00 游览《象鼻山》公园，打卡桂林城徽
  • 18:00 晚餐：桂林恭城油茶 + 桂林米粉
  • 19:30 夜游《两江四湖》，赏桂林夜景

第二天

🚣 漓江精华 · 阳朔风光

全程漓江两岸 · 山水画廊

  • 08:00 前往《竹江码头》，乘坐漓江竹筏漂流
  • 09:00 漂流精华段：九马画山、黄布倒影（21元人民币背景）
  • 12:00 抵达兴坪古镇，午餐品尝啤酒鱼
  • 14:00 游览阳朔《十里画廊》，骑行体验
  • 17:00 入住阳朔西街特色民宿
  • 19:00 晚餐：阳朔啤酒鱼 + 荔浦芋扣肉
  • 20:00 观赏《印象刘三姐》实景演出
第三天

🏞️ 阳朔 → 德天瀑布（跨国大瀑布）

全程约300公里，途经中越边境风光

  • 07:30 早餐后出发，沿中越边境公路前往德天瀑布
  • 12:00 抵达硕龙镇，午餐品尝边境特色菜肴
  • 13:30 游览《德天跨国大瀑布》，乘竹筏近距离观瀑
  • 15:00 漫步界碑旁，感受一瀑跨两国的奇观
  • 17:00 入住大新明仕田园景区民宿
  • 18:30 晚餐：明仕稻田宴 + 壮家糯米酒
第四天

🎋 明仕田园 → 南宁（东盟之都）

田园风光 → 城市美食

  • 07:30 晨骑明仕田园，感受喀斯特田园风光
  • 09:00 游览《黑水河》，体验原始自然风光
  • 11:00 出发前往南宁（约3小时车程）
  • 14:00 抵达南宁，入住酒店休息
  • 15:00 游览《青秀山》风景区，登高俯瞰南宁
  • 18:00 晚餐：南宁老友粉 + 东盟美食街大满足
  • 20:00 夜游《邕江》夜景，漫步南湖公园
第五天

🏖️ 南宁 → 北海银滩

海滨放松 + 返程深圳

  • 08:00 早餐后出发前往北海（约2.5小时）
  • 10:30 抵达北海《银滩》，沙滩休闲、踏浪拍照
  • 12:00 午餐：北海海鲜大餐（鱿鱼、生蚝、皮皮虾）
  • 14:00 游览《北海老街》，购买特产纪念品
  • 16:00 从北海乘车/高铁返回深圳
  • 20:00 预计抵达深圳，结束愉快的旅程
