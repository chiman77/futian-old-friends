# 福田老友记 - 部署指南

## 前提准备

1. 安装 Git（已确认已安装）
2. 注册 GitHub 和 Vercel 账号

---

## 一、部署到 GitHub Pages

### 步骤 1：在 GitHub 创建仓库

1. 打开 https://github.com/new
2. 仓库名填 futian-old-friends
3. 选择 Public
4. 不要勾选 Initialize with README
5. 点击 Create repository

### 步骤 2：推送代码到 GitHub

复制以下命令执行（替换 YOUR_USERNAME）：

    cd C:\Users\chima\OneDrive\Documents\Futian\futian-old-friends
    git remote add origin https://github.com/YOUR_USERNAME/futian-old-friends.git
    git branch -M main
    git push -u origin main

### 步骤 3：开启 GitHub Pages

1. 打开你的 GitHub 仓库页面
2. Settings -> Pages -> 左侧
3. Source 选择 Deploy from a branch
4. Branch 选择 main / Root
5. 点击 Save
6. 等待 1-3 分钟，会得到地址：
   https://YOUR_USERNAME.github.io/futian-old-friends/

---

## 二、部署到 Vercel

### 方法 A：Vercel CLI

1. 安装 Vercel CLI：
    npm i -g vercel

2. 登录并部署：
    cd C:\Users\chima\OneDrive\Documents\Futian\futian-old-friends
    vercel login
    vercel

3. 按提示选择：
   - Set up and deploy? Yes
   - 选你的账号
   - Link to existing? No
   - Project name: futian-old-friends
   - Deploy? Yes

4. 得到链接：https://futian-old-friends-xxx.vercel.app

### 方法 B：Vercel 网页

1. 打开 https://vercel.com/new
2. 用 GitHub 登录
3. Import Git Repository，选择 futian-old-friends 仓库
4. Framework Preset 选 Other
5. 点击 Deploy

---

## 三、部署到 Netlify（拖拽最省心）

### 最简单方式：拖拽部署

1. 打开 https://app.netlify.com/drop
2. 把 futian-old-friends 文件夹拖到上传区域
3. 等待 10-20 秒
4. 立即获得 https://xxx.netlify.app 的链接
